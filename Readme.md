## Copilot CLI

Presentation: `DevDays-Copilot CLI-Emre.pptx`

- **Riding the waves:** evolution from code completion (2021-2023) to pair programmer (2024-2025) to hybrid teams of humans + agents (2026+), i.e. the agentic SDLC.
- **Slash commands:** `/agent`, `/model`, `/plan`, `/mcp`, `/cd`, `/fork`, `/yolo`, `/context`, `/diff`, `/review`, `/skills`, `/sandbox`, `/every` & `/after`, `/rubber-duck`, `/remote`, `/delegate`, `/fleet`.
- **Planning with a team of agents:** using `/plan` with multiple agents.
- **Delegating to the cloud:** `/delegate` pushes work to Copilot cloud agent on GitHub.
- **Context management:** `/context` and `/compact`; Infinite Sessions is a CLI exclusive.
- **Custom agents:** two agents with two roles; an agent is a command.
- **Copilot CLI in pipelines:** automation use, e.g. an agent finding a bug.
- **Copilot Fusion:** a model orchestrator, not a model.
- **Three patterns** and a live demo.
